# RecoverAI
**Find revenue at risk. Choose the right intervention. Recover it with bounded AI workflows.**

## Project Overview
RecoverAI is an autonomous revenue recovery agent that detects revenue at risk, diagnoses its root cause, predicts the probability and economics of recovery, selects the right intervention, executes a bounded workflow, stops when recovery conditions are met or limits are reached, escalates cases requiring human attention, and provides a complete audit trail of measured revenue recovered.

## Tech Stack
- Frontend: Next.js, Tailwind CSS
- Backend: FastAPI, SQLAlchemy, PostgreSQL
- AI/ML: Qwen (via Ollama)
